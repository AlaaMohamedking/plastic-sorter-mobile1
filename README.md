# نظام فرز البلاستيك - نسخة الموبايل

تطبيق أندرويد (Kivy) بديل لبرنامج سطح المكتب. الموبايل هو الجهاز الوحيد:
كاميرا الموبايل تقرأ اللون، والموبايل يبعت أوامر للأردوينو عن طريق **كابل USB مباشر (OTG)**
— بالظبط زي ما كان متوصل بالكمبيوتر، غير إن السلك دلوقتي واصل فى الموبايل بدل الكمبيوتر.

---

## 1) الهاردوير

مفيش أي تعديل مطلوب على الأردوينو أو الريليهات — نفس التوصيلات. المطلوب بس:

- **كابل OTG** يناسب منفذ شحن موبايلك (USB-C غالباً فى الموبايلات الحديثة، أو Micro-USB فى الأقدم)
  من نوع "USB-C to USB-A Female" أو "Micro-USB to USB-A Female" — تلاقيه فى أي محل أكسسوارات موبايلات.
- سلك USB عادى (زي اللي بيجي مع الأردوينو) بين الـ OTG وبورت الأردوينو.
- تأكد إن موبايلك بيدعم **USB Host / OTG** (أغلب موبايلات أندرويد من 2016 لغاية دلوقتي بتدعمها).

ارفع كود `arduino/plastic_sorter_usb/plastic_sorter_usb.ino` على الأردوينو من Arduino IDE
(نفس بروتوكول الأوامر بتاع برنامج الكمبيوتر بالظبط: `R:idx:0/1`, `P:idx:ms`, `A`).

> لو الريليهات متوصلة على أرقام بينات مختلفة، غيّر مصفوفة `RELAY_PINS` فى بداية ملف الـ ino.

---

## 2) بناء ملف APK

الطريقة الموصى بيها: **GitHub Actions** (بناء أونلاين، مش محتاج تثبت حاجة على جهازك).

1. اعمل حساب على GitHub وارفع مجلد المشروع ده كامل على repository جديد.
2. أضف ملف باسم `.github/workflows/build.yml` بالمحتوى ده:

```yaml
name: Build APK
on: [push, workflow_dispatch]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install buildozer
        run: pip install buildozer cython==0.29.36
      - name: Build APK
        run: buildozer -v android debug
      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: apk
          path: bin/*.apk
```

3. روح لتبويب "Actions" فى المستودع — البناء هيبدأ تلقائياً (أو دوس "Run workflow" لو مبدأش).
4. بعد 20-30 دقيقة هتلاقي ملف الـ APK جاهز للتنزيل تحت "Artifacts".

(البديل: بناء محلي عندك بـ WSL + Buildozer لو عندك ويندوز ومحتاج تتجنب الرفع على GitHub — اسأل لو عايز تفاصيل الطريقة دي.)

---

## 3) تثبيت الـ APK على الموبايل (من غير جوجل بلاي)

1. انسخ ملف الـ APK للموبايل (كابل USB، أو Google Drive/تليجرام).
2. من إعدادات الموبايل فعّل "تثبيت من مصادر غير معروفة" لتطبيق الملفات اللي هتفتح بيه الملف.
3. افتح الملف واضغط تثبيت.
4. أول ما تفتح التطبيق هيطلب إذن الكاميرا فقط — وافق عليه.

---

## 4) توصيل الأردوينو من داخل التطبيق

1. وصّل كابل الـ OTG بين الموبايل والأردوينو (والأردوينو موصّل بالكهرباء عادي).
2. افتح تبويب **"USB / الأردوينو"** فى التطبيق.
3. دوس **"تحديث قائمة أجهزة USB"** — المفروض يظهر اسم الجهاز.
4. دوس **"اتصال"**. أول مرة هيظهرلك تنبيه من أندرويد نفسه يطلب إذن الوصول لجهاز الـ USB — وافق عليه،
   وبعدين دوس "اتصال" تانى.
5. لو ظهرت "الحالة: متصل" يبقى تمام، وتقدر تبدأ تستخدم باقي التبويبات عادي.

---

## 5) ملاحظات مهمة

- **الأداء**: قراءة لون كل إطار بتتم بحلقة بايثون بسيطة على منطقة صغيرة فى نص الشاشة
  (25% من أصغر بُعد)، عشان تفضل سريعة على الموبايل. لو حسيت إن القراءة بطيئة قلل حجم منطقة
  القراءة من دالة `_analyze_frame` فى `main.py`.
- سرعة الاتصال (Baud) متظبطة على `115200` فى كل من `usb_serial_link.py` وملف الـ `.ino` —
  لو غيّرت واحد لازم تغيّر التانى بنفس القيمة.
- التطبيق بيحفظ كل الإعدادات (العينات، الخلفية، تسميات الريليهات...) تلقائياً على الموبايل نفسه.
- زرار "إيقاف الكل" شغال فى كل وقت أسفل الشاشة زى نسخة الكمبيوتر بالظبط.
- ملفات المشروع:
  - `main.py` — التطبيق الرئيسى وكل التبويبات
  - `color_utils.py` — نفس معادلات CIELAB / Delta E
  - `usb_serial_link.py` — الاتصال بالأردوينو عبر USB/OTG (وفيه وضع محاكاة للتجربة على الكمبيوتر)
  - `storage.py` — حفظ/تحميل الإعدادات
  - `arabic_text.py` — إصلاح شكل النص العربى داخل Kivy
  - `buildozer.spec` — إعدادات بناء الـ APK
  - `arduino/plastic_sorter_usb/plastic_sorter_usb.ino` — كود الأردوينو (USB بس)
